# Orbit

Ebeveyn denetim sistemi: çocuk telefonları için Android uygulaması (device owner), ebeveynler için PWA paneli, Supabase arka uç.

- `android/` — çocuk telefonu uygulaması (Kotlin)
- `web/` — ebeveyn paneli (Next.js PWA, Vercel)
- `supabase/` — veritabanı şeması ve migration dosyaları (`orbit` şeması, Noor projesi)
